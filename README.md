# The Nifty Chronicles

Market comics featuring Captain Nifty.

## Publish a new issue

Open the `issues/` folder on GitHub, choose **Add file → Upload files**, then upload the comic as a self-contained HTML file. Give each new issue its own filename and commit to `main`. Its HTML title becomes the archive entry. The archive groups issues by the date of the commit that first added each file, in India time.

[Visit the archive](https://sriniurs.github.io/nifty-comics/)
